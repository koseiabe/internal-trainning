=== デバッグモード

* `set -x`:デバッグモード
* `set +x`:デバッグモード解除 +
※\#!/bin/bashの後に"-x"を付けるとファイル全体をデバッグモードにすることができる
* デバッグscript: https://github.com/koseiabe/internal-trainning/tree/main/script/day17/17_03_debug.sh +

|===

=== Corn
#決められた時間にコマンドやスクリプトを実行する機能# +

* `#分 時間 日 月 曜日 <ユーザ名> <実行コマンド>`:Cornフォーマット#
* `-`:幅を表す（0-9:０時から９時）
* `,`:リストを表す（0,3,14:0,3,14時）
* `/`:間隔を表す（*/3:0,3,6,9,...,21時）
 +
* `/etc/cron.d`:いつ実行するのか設定を記述したファイルを格納するディレクトリ
* `/etc/cron.{hourly,daily,weekly,monthly}/`:毎時、毎日、毎週、毎月に実行されるジョブを格納するディレクトリ
* `/etc/crontab`:ジョブを記載するファイル +
※これらのディレクトリやファイルはrootユーザ権限
* `#crontab`:cron設定用コマンド +
※各ユーザーのcron設定用のファイル"/var/spool/cron"を編集・表示する +

|===
| crontab コマンドオプション
|`-u`:ユーザー名指定
|`-l`:cronの設定を表示
|`-e`:cronを設定
|===

* `run-parts` と記述することで指定したディレクトリの中にあるスクリプトをアルファベット順ですべて実行してくれる



== セクション１９：systemctl,圧縮解凍,リソース解析

=== init プロセス
* システム起動時に最初に起動され、他のプロセスを起動する役目を持ったプロセス +
※全プロセスの根源 +
* initプロセスの種類:systemd


=== systemctl
#systemdで制御しているサービスを管理するコマンド# +

* `systemctl <オプション> <サービス名>`:コマンドフォーマット
* `/etc/systemd/system` `/usr/lib/systemd/system`:この２つのディレクトリに各サービスの設定を記述したファイルを格納している
* `Unit(ユニット)`:systemdが立ち上げるプログラムの単位

|===
|設定内容一覧例
|[Unit]
Description=My Custom Python App (自作アプリの概要)
After=network.target            # ネットワークが繋がってから起動
 +
\[Service]
Type=simple
User=myuser                    # セキュリティのため一般ユーザーで実行
ExecStart=/usr/bin/python3 /opt/myapp/app.py  # 動かしたいコマンド
Restart=always                 # 落ちたら自動再起動！
 +
\[Install]
WantedBy=multi-user.target     # 通常のOS起動時に自動起動させるための設定
|===


* デーモン化:バックグラウンドで動き続ける状態にすること
* バイナリファイル:テキストとして読めない２新数のデータで構成されたファイル
* コンパイル:ソースコード（人間が書いたプログラミング言語）をコンピュータが直接理解できる言葉に翻訳する作業


=== 圧縮解凍(gzip)
圧縮例：gzip <ファイル名> +
* `gzip -r`:ディレクトリ内ファイルも再帰的に圧縮
* `gzip -d`:ファイルを解凍 +
例：gzip -d <ファイル名.gz>


=== 圧縮解凍(zip,unzip)
#元のファイルを残した状態で圧縮できる# +

* windosでよく用いられる +
圧縮例：zip <圧縮ファイル名> <圧縮したいファイル> +
* `zip -r`:再帰的圧縮
* `unzip <解凍したいファイル.zip>`:ファイル解凍 +


=== ★ tar コマンド
#圧縮解凍するコマンド# +

* `-c`:圧縮
* `-x`:解凍
* `-f`:対象ファイル・ディレクトリ指定
* `-v`:処理されたファイル一覧表示
* `-z`:gzip形式で（拡張子が.tar.gz）
* `-J`:xz形式で（.tar.xz） +
例："tar -xvfJ <解凍したファイル.tar.xz>" +
例："tar -zcvf <圧縮名.tar.gz> <圧縮したいファイル>" +
