== セクション１２:標準出力,エラー出力,ファイル入出力


=== 標準出力:「１」
* `#>#`:上書き
* `>>`:追記
* 標準出力スクリプト: https://github.com/koseiabe/internal-trainning/blob/main/script/day11/11_01_file_input.sh


=== エラー出力:「２」
* `#2>#`:標準エラー出力をファイルに上書き
* `2>>`:標準エラー出力をファイルに追記
* `./11_02_error_output.sh 1> 1.txt 2> 2.txt`:標準出力を"1.txt"、標準エラー出力を"2.txt"に送ることができる
* 標準エラー出力スクリプト:https://github.com/koseiabe/internal-trainning/blob/main/script/day11/11_02_error_output.sh


=== 出力の特殊な書き方
* `#&>#`:標準とエラー出力を同じファイルに出力する
* `2>&1`:標準エラーを標準出力と一緒の設定にする +
※例:./11_02_error_output.sh > output.txt 2>&1
* `#&> /dev/null#`:標準出力もエラー出力も画面上にもファイルにも出力しない


=== ファイル入力
* `file=$(cat file.txt)`:catの実行結果を変数に格納
* `cat <ファイル名> | while`:ファイルの中身をループさせる +
※while内の処理はサブシェルと呼び、while外の変数を変更しても変更は反映されない
* whileでファイル読みスクリプト: https://github.com/koseiabe/internal-trainning/blob/main/script/day11/11_03_file_input.sh
* 演習(ループを使ったファイル内計算)スクリプト:https://github.com/koseiabe/internal-trainning/blob/main/script/day11/11_04_exam.sh



== セクション１３:相対パス,絶対パス,終了ステータス,&& ||での実行


=== realpath:指定したファイル・ディレクトリの絶対パスを表示
* `#realpath <ファイル名>#` +
※例：#full_path=$(realpath ${0})#
* realpath活用スクリプト: https://github.com/koseiabe/internal-trainning/blob/main/script/day12/project/bin/program.sh

=== dirname:ファイル・ディレクトリの絶対パス名から親ディレクトリ名を取得
* `#dirname <絶対パス名>#`
※例：#bin_path=$(dirname "${full_path"})#
* dirname活用スクリプト: https://github.com/koseiabe/internal-trainning/blob/main/script/day12/project/bin/program.sh

=== リンクを用いたファイル実行
* `in -s <リンク作成したいファイルの絶対パス> <環境変数のディレクトリ>`:環境変数設定されているディレクトリ内にリンクを作成することで、リンク名だけで実行できるようになる


=== 終了ステータス:コマンドが成功か失敗かを表すコード
* ステータスが"0"なら成功、"0"以外なら失敗
* `echo $?`:直前のコマンド結果の終了ステータスを確認する

.終了ステータス,意味・発生する主な原因,具体例
|===
|終了ステータス　|発生原因　|具体例

|0
|成功（正常終了）
|コマンドがエラーなしで完了した状態。

|1
|一般的なエラー
|0除算（割り算の分母が0）や、一般的なコマンドの失敗など。

|2
|シェルの誤用 / 構文エラー
|先ほど発生していた while の done 閉じ忘れや、権限エラーなど。

|126
|コマンドが実行不能
|ファイルはあるが、実行権限（chmod +x）が付いていないとき。

|127
|コマンドが見つからない
|タイポ（打ち間違い）や、$PATH の中にコマンドが存在しないとき。

|128
|exitへの不正な引数
|exit 3.14 のように整数以外の値を指定して終了しようとした。

|128 + n
|シグナル n による強制終了
|例：130（128 + 2）は、実行中に Ctrl + C で強制終了したサイン。

|255
|終了ステータスの範囲外
|終了ステータスは 0〜255 の範囲しか使えないため、枠を超えた時。
|===

* 終了ステータス応用スクリプト:  https://github.com/koseiabe/internal-trainning/script/day12/12_01_exit.sh
* 終了ステータス応用スクリプト:  https://github.com/koseiabe/internal-trainning/script/day12/12_01_external.sh


=== &&,||
* `#<コマンド> #&&# <コマンド>#`:前のコマンドが#成功#したら後のコマンドを実行する
* `#<コマンド> #||# <コマンド>#`:前のコマンドが#失敗#したら後のコマンドを実行する
* `#<A> && <B> || <C>#`:コマンドAが成功したらBが実行され、A,Bどちらか失敗したらCが実行される +
※"||"の認識に注意



== セクション１４:ファイル、標準出力操作

=== cutコマンド：ファイルや標準出力から行ごとに一部の文字を切り取る
* `-c`:取り出す文字の位置を指定して取り出す +
※ echo "ABCDE" | cut -c "1,3,4" →"ACD"のみ取り出される
* `-f`:取り出すファール度番号を指定する
* `-d`:区切り文字(デリミタ)を指定する +
※ cat 13_01_cut.txt | cut -d " " -f "2" →区切り文字" "にして、フィールドの2つ目を取り出す


=== tr:文字列の変換・消去
* `-d`:指定した文字を削除 +
`echo "AAAB" | tr -d "A"` →この場合、"B"だけ表示される
* `-s`:指定した文字が連続したとき１つにする +
`echo "AAAB" | tr -s "A"` →この場合、"AB"という結果で表示される


=== sedコマンド:テキストやファイルの一部の文字を削除・置換する
* `#sed "アクション" <ファイル名>#`:基本的な形式
* `#"s/〇〇/××/g"`:ファイルの各行の〇〇を××に変換し標準出力する#
* `#"2d"#`:ファイル内の2行目を消した形で標準出力 +
※この時ファイル自体から2行目は消えない
* `"/unix/d"`:ファイル内の"unix"と記述された行のみ削除され標準出力
* `#sed -i#`:標準出力ではなく、ファイル自体に反映させる



=== sortコマンド:ファイルの行を降順または昇順に並び替えて出力する
* `-r`:降順
* `-b`:行頭に空白があっても無視する
* `-n`:数値基準で並び替える
* `-t <デリミタ>`:指定した文字を区切り文字とする
* `-k n`:n番目をソート対象にして並び替える

|===
|sort -r -t "," -k 3 13_03_sort2.txt
|3, pine, 500円 +
2, banana, 400円 +
1, apple, 300円 +
4, grame, 200円
|===


=== uniqコマンド：並び替えられた文字列から超副業を１つにして出力する
* `-i`:大文字、小文字区別しない
* `-d`:重複している行のみ取り出す
* `-u`:重複していない行のみ取り出す


=== joinコマンド：2つのファイルから列の値が共通する要素に対して結合する
* `#join -1 〇〇 -2 ×× <ファイル名２> <ファイル名２>#`:ファイル１の〇〇列とファイル２の××列でつなげる
* `-t ","`:カンマ区切りの文字に対して結合する
* `-a 1`:共通する要素とともにファイル１に存在しファイル２に存在しない列を表示する
* `-v 1`:ファイル１に存在しファイル２に存在しない列のみを表示する

|===
join -t "," -1 2 -2 1 13_05_join2.txt 13_05_join3.txt +
14歳,1,寅年 +
15歳,3,うさぎ年
|===


=== grepコマンド
* `-v 〇〇`:〇〇を含まない行だけ取り出す
* `-n`:行数も表示


=== awkコマンド:ファイルや標準出力から、行ごとに何らかの処理を行いたい場合に用いる
* `#awk '{行いたい処理}'#`
* `BEGIN{}`:awk実行前に実行される前処理
* `END{}`:awk実行後に実行される後処理　
* awkコマンド詳細: https://www.tohoho-web.com/ex/awk.html

|===
|実行例
|`awk '/〇〇/ {print}'\ <ファイル名>`:ファイルから〇〇を含んでいる行を取り出す
|`awk -F "," '{print $1,$4}'\ <ファイル名>`:ファイルからカンマ区切りで1行目と4行目を取り出す +
|`awk '{if($2=="clerk") print NR,$1,$3}'\ <ファイル名>`:ファイルの2列目がcleakだけ取り出す
|===
* awkの中の文はC言語を使っているためbashを使うより早い
