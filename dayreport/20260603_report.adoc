== セクション１０：標準入力、引数、if文


=== if形式１: #if test <条件文>; then#

|===
|文字列の比較
|`==`: 等しいか    ("$\{OS}" == "Linux")
|`!=`:等しくないか ("$\{OS}" != "Linux")
|===

|===
name="$\{1}" +
age="$\{2}" +
`if test "${name}" == "Taro"; then` +
 echo "あなたの名前は太郎です" +
`elif test "${name}" != "Hanako"; then` +
 echo "あなたの名前花子ではないです" +
`else` +
 echo "あなたの名前は花子です" +
`fi` +
|===

|===
|数値の比較
|`-eq`:等しいか(equal)
|`-ne`:等しくないか(not equal)
|`-it`:より小さいか(less than)
|`-le`:以下か(less equal)
|`-gt`:より大きいか(greater than)
|`-ge`:以上か(greater equal)
|===

|===
`if test "$\{age}" -ge 60; then` #60以上 +
 echo "60以上" +
`elif test "$\{age}" -gt 20; then` #20より大きい +
 echo "21\~59" +
`else` +
 echo "20以下" +
`fi` +
|===

=== if形式2: #if [<条件文>]; then#
* `if [ "${name}" == "Taro" ]; then`
* `elif [ "${name}" != "Hanako" ]; then`


=== if形式3: #if [[<条件文>]]; then#
* `if [[ "${name}" == "Taro" ]]; then`
* `elif [[ "${name}" != "Hanako" ]]; then`


=== if形式４(数値比較):　#if\((条件式)); then#
* `if (( "${age}" >= 60 )); then` #60以上か
* `elif (( "${age}" > 20 )); then` #20より大きいか +
※\((条件文))の形式の際は、数値比較時に"<","<="を使っても正しく数値が認識される


=== if文否定：条件式を満たさない場合に実行
* `if [[ #!# 条件式 ]]; then`
* `if #!# \(( 条件式　)); then`

=== if文「OR」:複数条件のどれかを満たす場合に実行
* `if [[ 条件式1 #||# 条件式2 ]]; then`
* `if (( 条件式1 #||# 条件式2 )); then`
* `if [ 条件式1 #-o# 条件式2 ]; then`

=== if文「AND」:複数条件をすべてを満たす場合に実行
* `if [[ 条件式1 #&&# 条件式2 ]]; then`
* `if (( 条件式1 #&&# 条件式2 )); then`
* `if [ 条件式1 #-a# 条件式2 ]; then`

|===
year=$(date "+%Y") +
#2026 +
year=2000 +
#4で割り切れて、100で割り切れない +
if (( "${year}" % 4 == 0 && "${year}" % 100 != 0 )); then +
echo "うるう年です" +
else +
echo "うるう年ではないです" +
fi 
|===

=== 特殊なif文
* `if [[ #-z# "${my_var}" ]]; then`:変数が設定されていない場合の処理
* `if [[ #-n# "${my_var}" ]]; then`:変数が設定されている場合の処理
* `if [[ "${name}" == #*Ta*# ]]; then`:変数にTaが含まれているか

|===
|ファイルチェック
|`[[ -e 〇〇]]`:〇〇ファイルや〇〇ディレクトリが存在する
|`[[ -f 〇〇]]`:ディレクトリでなく〇〇ファイルが存在する
|`[[ -d 〇〇]]`:ファイルでなく〇〇ディレクトリが存在する
|`[[ -w 〇〇]]`:書き込み権限があるか
|`[[ -x 〇〇]]`:実行権限があるか
|`[[ fileA -nt fileB ]]`:fileAがfileBより新しいか
|`[[ fileA -ot fileB ]]`:fileAがfileBより古いか
|===


== セクション１１：ループ処理

=== for

|===
|nameにいれたnamesの要素を一つ一つをループ処理
|names="Taro Jiro Saburo" ←変数namesに値を設定 +
#for name in $\{names}# ←#※$\{names}の前後に""を付けない# +
do +
		echo "name: $\{name}" +
done
|===
* `#for name in ${}`:${}に入れた値がループ処理される#
* 変数の前後に""を付けない理由は、要素をスペースで区切った場合に一つの文字列として判断されてしまうため

|===
|変数numberに０～５までの値を入れ2つ飛ばしでループ
|#for number in ${0..5..2}# +
do +
		echo "$\{number}" +
done
|===
※seqコマンドでも実行することができる。${ seq 0 2 5}で２つ飛ばし


=== 辞書利用:配列要素に対応する値を入れることができる
|===
|配列要素と各要素に対応する値を出力

\#要素に対応する値を入れる +

salaries['Hanako']=1500000 +
salaries['Yoshiko']=1250000 +

\#要素をループして取り出すには、#${!<配列名>[@]}#とする
#for i in "${!salaries[@]}"# +

   #echo "${i}: ${salaries[${i}]}"# +
done
|===


=== continueとbreak
* `continue`:処理を飛ばすことことができる +
※特定の条件下で処理を飛ばしたい場合に用いられる
* `break`:処理を終了させる

|===
|演習
|#0 ~ 100 +
#15で割り切れたらFB +
#15で割り切れないが、３で割り切れるF +
#15で割り切れないが５で割り切れるB +

for i in {0..100} +
do +
  if (( i % 15 == 0 )); then +
    echo "${i}: FB" +
  elif (( i % 3 == 0 )); then +
    echo "${i}: F" +
    #continue# +
  elif (( i % 5 == 0 )); then +
    echo "${i}: B" +
    continue +
  fi +
done +
|===



=== while:指定条件を満たしている間はループする
* whileループは条件を満たしている間無限ループしてしまうため、終了どころを必ず記述する 

|===
|変数が１０以上になるまでループ
|counter=1 +
#while (( "${counter}" <= 10 ))# +
do +
   echo "counter: ${counter}" +
   (( counter++ )) +
done
|===


=== until:指定条件を満たすまでループする
* whileループの逆 

|===
|応用演習
|# 数字を当てるゲーム +
random_value=$(( ${RANDOM} % 101 )) #0\~100 +
 +
answer=-1 #0\~100でない数字 +
counter=0 #試行回数 +
 +
while \(( "${answer}" != "${random_value}" )) +
do +
        read -p "答えと思う数字を入力してください" answer +
        \(( counter++ )) +
        if \(( "${answer}" < "${random_value}" )); then +
              echo "もう少し大きい値です" +
        elif \(( "${answer}" > "${random_value}" )); then +
              echo "もう少し小さい値です" +
        elif \(( "${answer}" == "${random_value}" )); then +
              echo "正解は${random_value}です。${counter}回で正解しました" +
        fi +
done +
|===
