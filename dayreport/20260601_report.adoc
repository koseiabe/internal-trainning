= セクション５



=== useradd  ユーザ追加
* `-g`:プライマリグループを指定
* `-d`:ホームディレクトリを指定
※/etc/passwdファイル内にユーザ一覧が記述


=== usermod　ユーザ情報変更
* `-i`:ユーザ名変更
* `-d`:ホームディレクトリ変更
* `-g`:プライマリグループを変更
* `-s`:ログインシェル変更
* `-L`:ログイン制限
* `-U`:ログイン制限解除


=== userdel  ユーザー削除


=== groupmod  グループ情報変更
* `-n`:グループ名を変更→groupmod -n <旧グループ名>　<新グループ名>
* `-g`:グループIDを変更→groupmod -g <新グループID> <ID変更したいグループ名>


=== passwd  パスワード変更


=== chown  指定したファイルやディレクトリ所有者、グループ変更
* `-R`:ディレクトリの中身の所有者も再帰的に変更
* `chown <所有ユーザ名>:<所有グループ名> <ファイル名>`:ファイルのユーザとグループを指定のものに変更


=== chmod  ファイルの権限を変更
* `-v`:実行したすべての処理の詳細（変更前後）を画面に表示
* `-R`:ディレクトリの中身のパーミッション値を再帰的に変更
* `chmod <パーミッション> <ファイル名>`:ファイルのパーミッション値を指定できる



= セクション6



=== ログインシェルの読み込み
"/etc/profile"を読み込む
↓
".bash_profile"を読み込む
↓
".bashrc"を読み込む（設定になっていることが多い）


=== Alias  コマンドの別名作成
* .bash_profileファイルにAliasを定義しておくと、ログイン時に読み込まれるため便利


=== プロンプト表示設定
* `PS1`:プロンプトを表示設定する環境変数

|===
|プロンプト設定時に利用する特殊文字
|`\h`:ホスト名
|`\u`:ログイン中ユーザ名
|`\W`:作業中ディレクトリ名
|`\t`:24時間の現在時刻表示
|`\@`:AM,PMつき時刻表示
|`\$()`:()内にあるコマンドの実行結果
|`\D{format}`:フォーマット指定
|===
* 例:PS1="[\u@\h \W \t \@]\$ "
※プロンプト表示設定も".bash_profile"に追記しておくと便利

|===
|プロンプト文字の色付け特殊文字
|`\e[`:カラーを指定するプロンプトの始まり
|`\e[m`:カラーを指定するプロプトの終わり
|`1;34m`:文字の色指定(明るい青文字)
|`42m`:バックグラウンドの色指定(緑色)
|===
* 例:PS1="\e[1;34m[\u@\h\e[m \W]\$"


=== ファイルシステム
* `/bin`:基本コマンドが格納されている
* `/etc`:主に設定ファイルが格納されている
* `/usr`:基本プログラムが配置されている
* `/opt`:主にOS作成時にインストールされるアプリが配置されている
* `/tmp`:一時的に容量の大きなファイルを格納(全ユーザー利用可能なためファイル共有などに利用)
* `/var`:ログファイル格納
* `/proc`:起動されたプロセス情報が格納されている(性能等の解析に用いられる)
※これらはディレクトリ


=== ハードリンク  ファイルのiノードに対するリンク
* ハードリンクは同じiノード値になる
* バックアップ用として利用される
* `lnコマンド <ファイル名> <リンク名>`:ハードリンクを作成
※ファイル自体が削除されても問題ない


=== シンボリックリンク  ファイル自体に対するリンク
* 主にファイルのショートカット用として利用
* ディレクトリでもシンボリックリンクは作成できる
* `ln -s <ファイル名> <リンク名>`:シンボリックリンクを作成
※ファイル自体を指すためファイルが削除されると消える



= セクション７



=== シェルスクリプト  Linux上で一連のコマンドが並んだプログラム(コマンド+プログラム文)
* シェルスクリプトファイルには末尾に".sh"といれておく
* "#"はコメント文であり実行されない
* `<変数名>=〇〇`:別名で格納される
* `$<変数名>`:変数でアクセスできる
* `sleep <秒数>`:指定した秒数待ちとなり実行される

|===
|#!bin/bash　→ファイルの先頭に記述するとシェルスクリプトとして認識する
|===

* プログラム実行は絶対パスか相対パスで行う
※実行権限が与えておくこと
* `.`,`source`:現在利用中のプロセス上でシェルスクリプトを実行するコマンド(親プロセスで実行)
* 環境変数：親プロセス・子プロセス両方で有効
※"bash_profile"に環境変数を設定しておくと便利
* シェル変数：子プロセスでは有効でない

|===
|`export <変数名>`:シェル変数を環境変数にできる
|`<変数名>=〇〇`:シェル変数作成
|`unset <変数名>`:シェル変数削除
|===

* `setコマンド`:環境変数、シェル変数、関数を一覧表示
* `printenvコマンド`:環境変数の一覧表示
