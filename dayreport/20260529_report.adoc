= vim

== コマンド操作
* vim -R  閲覧のみでファイルを開く


== コマンドモード操作
* ":e!" ファイルを開いたときの状態に戻る

=== カーソル移動
* "h" 左
* "l" 右
* "k" 上
* "j" 下
* "w" 単語単位
* "0" 行頭
* "$" 行末
* "gg" ファイル先頭
* "shift+g" ファイル最後

=== ページ移動
* "ctrl+f" 次のページ
* "ctrl+b" 前のページ

=== 行数表示
* ":set nu" 行数表示

=== コピー貼りつけ
* "yy" 行コピー
* "p" カーソル下行に貼りつけ
* "shift+p" カーソル上行に貼りつけ
* "y3y" 指定した行数コピー

=== 検索
* "/" 指定したものを検索
* "n" 次を検索
* "shift+n" 前を検索

=== 直前動作
* "u" 元に戻す
* "ctrl+r" "u"の動作を取消す

=== 置換
* ":s/a/b" カーソル行のaをに置換
* ":%s/a/b/gc" ファイル全体のaをbに一つ一つ確認しながら置換
* y:置換する n:置換しない a:以降すべて置換 q:置換終了 l:カーソル行すべて置換 ctrl+e:上にスクロール ctrl+y:下にスクロール

=== インデント
* ">>" 右に揃える
* "<<" 左に揃える
* "==" 他行と揃える

=== ビジュアルモード
* "v" ビジュアルモード切り替え
* "ctrl+v" 矩形選択ビジュアルモード
※範囲選択後に"shift+i"で編集モードに変更、選択範囲の先頭に文字入力し"escキー"を押すと範囲選択の先頭に同じ文字が反映される。

=== ファイル編集途中に別ファイルへ移動
* "ctrl+z" 一時的にファイルから離れる
※元のファイルに戻るときはプロンプト上で"fg"コマンドを実行すると戻れる。

=== 画面分割
* ":vs" 左右に画面分割
* "sp" 上下に画面分割
* "ctrl+w ctrl+w" 画面切り替える
* ":close" 現在いる画面を閉じる
* ":only" 他に開いている画面を閉じる
* ":e ファイル名" 別ファイルを画面分割で表示できる

== 編集モード
* "a" カーソル後から編集モードに切り替え
* "shift+a" 行末から編集モードに切り替え
* "shift+i" 行頭から編集モードに切り替え
* "zz" 保存して終了
