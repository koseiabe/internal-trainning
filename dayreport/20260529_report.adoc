= これまでの復習

== pushまでの流れ
* `git add <ファイル名>`
* `git commit <ファイル名>`
* `git remote add <リモート名> <リモートリポジトリのURL>`
* `git push <リモート名> <ブランチ名>`

= vim

== vimコマンド操作
* `vim -R <ファイル名>`:閲覧のみでファイルを開く

=== 編集モード
* `a` カーソル後から編集モードに切り替え
* `shift+a` 行末から編集モードに切り替え
* `shift+i` 行頭から編集モードに切り替え
* `zz` 保存して終了

=== コマンドモード操作
* `:e!`:ファイルを開いたときの状態に戻る

=== カーソル・行移動
* `h`:左
* `l`:右
* `k`:上
* `j`:下
* `w`:単語単位
* `0`:行頭
* `$`:行末
* `g`:ファイル先頭
* `G`:ファイルの一番下
* `shift+g`:ファイル最後
* `100G`:100行目移動
* `o` 下に行追加
* `A` カーソルの行末から入力モードに


=== ページ移動
* `ctrl+f`:次のページ
* `ctrl+b`:前のページ

=== 行数表示
* `:set nu`:行数表示

=== コピー貼りつけ
* `yy`:行コピー
* `p`:カーソル下行に貼りつけ
* `shift+p`:カーソル上行に貼りつけ
* `y3y`:指定した行数コピー

=== 検索
* `/`:指定したものを検索
* `n`:次を検索
* `shift+n`:前を検索

=== 直前動作
* `u`:元に戻す
* `ctrl+r`:ctrl+uの動作を取消す

=== 置換
* `:s/a/b`:カーソル行のaをに置換
* `:%s/a/b/gc`:ファイル全体のaをbに一つ一つ確認しながら置換

|===
|:%s/a/b/gc 時の操作
|y |置換する 
|n |置換しない
|a |以降すべて置換
|q |置換終了
|l |カーソル行すべて置換
|ctrl+e |上にスクロール 
|ctrl+y |下にスクロール
|===

* `:%s/A/a/g`:大文字Aを小文字aに置換

=== インデント
* `>>` 右に揃える
* `<<` 左に揃える
* `==` 他行と揃える

=== ビジュアルモード
* `v` ビジュアルモード切り替え
* `ctrl+v` 矩形選択ビジュアルモード
※範囲選択後にshift+iで編集モードに変更、選択範囲の先頭に文字入力しescキーを押すと範囲選択の先頭に同じ文字が反映される。

=== ファイル編集途中に別ファイルへ移動
* `ctrl+z` 一時的にファイルから離れる
※元のファイルに戻るときはプロンプト上でfgコマンドを実行すると戻れる。

=== 画面分割
* `:vsp` 左右に画面分割
* `:sp` 上下に画面分割
* `ctrl+w ctrl+w` 画面切り替える
* `:close` 現在いる画面を閉じる
* `:only` 他に開いている画面を閉じる
* `:e <ファイル名>` 別ファイルを画面分割で表示できる

=== コマンド実行
* `:!コマンド`:vi起動中にコマンドが実行できる
* `:!%:p`:編集中のファイルの実行
※実行する前に:wで保存すること


== bash

=== man  コマンドのマニュアル表示
* `-d`:半画面下に　
* `-u`:半画面上に


=== date  日時表示


=== echo  引数に入力した文字列を表示
* `-e`:指定することでバックスラッシュを特殊文字として解釈する
* `\n`:改行`

=== touch  ファイル作成やタイムスタンプの変更
* `-a`:ファイルのアクセス日時変更
* `-m`:更新日時変更
* `-d`:作成日時を指定してファイル作成

=== ls  ディレクトリ内を表示
* `-1`:ファイル名のみを縦表示


=== stat  ファイルを指定して詳細表示


=== mkdir  ディレクトリ作成
* `-p`:ディレクトリ内にディレクトリを作成

=== cp  ファイルディレクトリを新たにコピーする
* `-p1`:元ファイルと同じ属性でコピーする
* `-i1`:ファイル名が同じものが存在している際に確認がある
* `-r1`:ディレクトリの中身ごとコピーする

=== cat  ファイルの中身を表示
* `-n`:行番号を付けて表示

* `-b`:空行に行番号を付けず表示

=== rmdir 空ディレクトリの削除
* `-p`:空ディレクトリ内も削除

=== rm  ファイルやディレクトリ削除
* `-f`:強制削除
* `-i`:確認有り削除
* `-r`:ディレクトリ削除

=== which  指定したプログラムのパス確認



== ショートカット

=== ctrl+  プロンプト上操作
* `ctrl+a`:左端移動
* `ctrl+e`:右端
* `ctrl+u`:カーソルの左位置から文頭までを削除
* `ctrl+k`:カーソルから文末まで削除
* `ctrl+w`:単語単で削除
* `ctrl+s`:入力内容がプロンプトに表示されなくなる
※解決する際はctrl+q


== vim

=== vim上コマンド操作
* `:vertical diffsplit <差分比較ファイル>`:2つのファイルを差分比較できる



== ユーザ・グループ

=== useradd  ユーザ追加
* `-g`:プライマリグループを指定
* `-d`:ホームディレクトリを指定
※/etc/passwdファイル内にユーザ一覧が記述
