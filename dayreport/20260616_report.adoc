= Ansible

== セクション４：ハンズオン実践

=== ★ ハンズオン２４：ロール準備、yum モジュール
デプロイ:: ユーザー利用できる状態にすること
データベースクラスター:: 不空数のデータベースサーバーを連携させて、全体として１つのデータベースシステムとして機能させる仕組み +

* クラスター化のメリット
** 高可用性：１台が故障しても別サーバーが自動で処理を引き継ぐ
** 拡張性：アクセスが集中した際に、処理分散が可能

[source, yaml]
----
    # 6. DBサーバーのインストール
    - name: Install PostgreSQL
      apt:
        name: postgresql-server
        state: present
        
    # 7. DBの初期化（Redhat系の場合）
    - name: Initialize Postgresql database
      command: postgresql-setup initdb

    # 8. DBの起動と自動起動有効化
    - name: Start Postgresql
      service:
        name: postgresql
        state: started
        enabled: true

    # 9. バージョン取得
    - name: Get Postgresql version
      command: psql --version

    # 10. ステータス取得
    -name: Get status of Postgresql service
     command: systemctl status postgresql
----
※ ubuntuの場合DBの初期化はインストール時に自動で行わるためタスクの実行はしなくてよい


=== ハンズオン２５：ロールの実施
* タスクの分割基準
** リソースの種類（WebサーバーとDBサーバーごとなど）
** 操作の種類（インストールと起動ごとなど）

* rolesディレクトリは基本的にplaybookと同じディレクトリ内に作成する

.playbook実行の場合の配置イメージ
[source, yaml]
----
my-ansible-project/        # プロジェクトのルートディレクトリ
├── site.yaml              # 実行するプレイブック
├── hosts                  # インベントリファイル（環境による）
└── roles/                 # 👈 ここに「roles」という名前で作る
    ├── webserver/         # 自作または取得したロール1
    │   ├── tasks/
    │   └── handlers/
    └── dbserver/          # 自作または取得したロール2
        ├── tasks/
        └── vars/
----

.Webserver用role
[source, yaml]
----
# roles/web_server_role/tasks/main.yaml
#       ↑ロール名

# 1. インストール（Ubuntu用にaptモジュールへ変更）
- name: Install the latest version of nginx
  ansible.builtin.apt:
    name: nginx
    state: present
    update_cache: true

# 2. 起動と自動起動有効化（1つのタスクにまとめられます）
- name: Start and Enable nginx service
  ansible.builtin.service:
    name: nginx
    state: started
    enabled: true

# 3. バージョン取得（registerとchanged_whenを追加）
- name: Get nginx Installed version
  ansible.builtin.command: nginx -v
  register: nginx_version
  changed_when: false

# 4. nginxのステータスを取得（registerとchanged_whenを追加）
- name: Get status of nginx service
  ansible.builtin.command: systemctl status nginx
  register: nginx_status
  changed_when: false

- name: Read external variable file
  include_vars: vars.yaml

# 5. コピー
- name: Ansible copy file to remote server
  copy:
    content: |
      <!DOCTYPE html>
      <html>
      <head>
      <meta charset="UTF-8">
      </head>
      <body>
      <h1>このページはcopyモジュールのcontentパラメータを使用してコピーしたページです！</h1>
      </body>
      </html>
    dest: "{{ html_path }}/index.html"
----

* rolesディレクトリ直下のディレクトリがロール名として認識される（web_server_role）
* web_server_roleディレクトリ直下にtasksというディレクトリを作成することが必須！
* tasksの直下にmain.yamlというファイルを作成する（基本はmain.yamlというファイル名が推奨）

.DBserver用role
[source, yaml]
----
# /roles/db_server_role/tasks/main.yaml

# 6. DBサーバーのインストール
- name: Install PostgreSQL
  apt:
    name: postgresql
    state: present

# 8. DBの起動と自動起動有効化
- name: Start Postgresql
  service:
    name: postgresql
    state: started
    enabled: true

# 9. バージョン取得
- name: Get Postgresql version
  command: psql --version

# 10. ステータス取得
- name: Get status of Postgresql service
  command: systemctl status postgresql
----

.ロールの実行playbook
[source, yaml]
----
- name: Setup nginx server on myserver list (host group)
  hosts:
    - devservers
  become: true

  roles:
    - web_server_role
    - db_server_role
----
