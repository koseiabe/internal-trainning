== セクション１４: ファイル、標準出力操作


=== cut コマンド
#ファイルや標準出力から行ごとに一部の文字を切り取る# +

* `-c`:取り出す文字の位置を指定して取り出す +
※ echo "ABCDE" | cut -c "1,3,4" →"ACD"のみ取り出される
* `-f`:取り出すフィールド番号を指定する
* `-d`:区切り文字(デリミタ)を指定する +
※ cat 13_01_cut.txt | cut -d " " -f "2" →区切り文字" "にして、フィールドの2つ目を取り出す


=== tr コマンド
#文字列の変換・消去# +
* `-d`:指定した文字を削除 +
`echo "AAAB" | tr -d "A"` →この場合、"B"だけ表示される
* `-s`:指定した文字が連続したとき１つにする +
`echo "AAAB" | tr -s "A"` →この場合、"AB"という結果で表示される


=== sed コマンド
#テキストやファイルの一部の文字を削除・置換する# +

* `#sed "アクション" <ファイル名>#`:基本的な形式
* `#"s/〇〇/××/g"`:ファイルの各行の〇〇を××に変換し標準出力する#
* `#"2d"#`:ファイル内の2行目を消した形で標準出力 +
※この時ファイル自体から2行目は消えない
* `"/unix/d"`:ファイル内の"unix"と記述された行のみ削除され標準出力
* `#sed -i#`:標準出力ではなく、ファイル自体に反映させる



=== sort コマンド
#ファイルの行を並び替えて出力する# +

* `-r`:降順
* `-b`:行頭に空白があっても無視する
* `-i`:大文字と小文字を区別しない
* `-n`:数値基準で並び替える
* `-t <デリミタ>`:指定した文字を区切り文字とする
* `-k n`:n番目をソート対象にして並び替える

|===
|sort -r -t "," -k 3 13_03_sort2.txt
|3, pine, 500円 +
2, banana, 400円 +
1, apple, 300円 +
4, grame, 200円
|===


=== uniq コマンド
#並び替えられた文字列から重複行を１つにして出力する# +

* `-i`:大文字、小文字区別しない
* `-d`:重複している行のみ取り出す
* `-u`:重複していない行のみ取り出す


=== join コマンド
#2つのファイルから列の値が共通している要素に対して結合する# +

* `#join -1 〇〇 -2 ×× <ファイル名２> <ファイル名２>#`:ファイル１の〇〇列とファイル２の××列でつなげる
* `-t ","`:カンマ区切りの文字に対して結合する
* `-a 1`:共通する要素とともにファイル１に存在しファイル２に存在しない列を表示する
* `-v 1`:ファイル１に存在しファイル２に存在しない列のみを表示する

|===
join -t "," -1 2 -2 1 13_05_join2.txt 13_05_join3.txt +
14歳,1,寅年 +
15歳,3,うさぎ年
|===


=== grep コマンド
* `-v 〇〇`:〇〇を含まない行だけ取り出す
* `-n`:行数も表示


=== ★awk コマンド
#ファイルや標準出力から、行ごとに何らかの処理を行いたい場合に用いる# +

* `#awk '{行いたい処理}'#`
* `BEGIN{}`:awk実行前に実行される前処理
* `END{}`:awk実行後に実行される後処理　
* awkコマンド詳細: https://www.tohoho-web.com/ex/awk.html

|===
|実行例
|`awk '/〇〇/ {print}'\ <ファイル名>`:ファイルから〇〇を含んでいる行を取り出す
|`awk -F "," '{print $1,$4}'\ <ファイル名>`:ファイルからカンマ区切りで1行目と4行目を取り出す +
|`awk '{if($2=="clerk") print NR,$1,$3}'\ <ファイル名>`:ファイルの2列目がcleakだけ取り出す
|===
* awkの中の文はC言語を使っているためbashを使うより早い


=== ★xargs コマンド(エックスアグス)
#標準出力から"|"で受け取った値をコマンドの引数として用いる# +

* `echo "One Two Three" | xargs mkdir`= "mkdir One Two Three" と同じ意味
* `-p`:コマンド実行するかどうか尋ねられる
* `-t`:実行されたコマンドが表示される
* `-I 〇〇`:〇〇を変数として、標準出力に渡す +
`echo "2026/06/05" | xargs -I @ touch -d "@" <ファイル名>`:echoの引数を"@"の箇所に用いる


=== head コマンド
#ファイルの行頭から指定した行数文表示# +

* `-n 〇`:〇行数指定
* `-c 〇`:〇バイト数取得

=== ★tail コマンド
#ファイルの行末から指定した行数文表示# +

* `-n`:行数指定
* `-c`:バイト数取得
* `-F`:ファイルの行末に追加されるテキストをリアルタイムに表示


=== history コマンド
#ログインユーザの実行したコマンドの履歴を表示# +

* /home/user/.bash_historyファイルの中に実行履歴が書き込まれている
* `-c`:現在接続中のセッションの履歴をすべて削除
* `[件数]`:指定した件数分最新の履歴を取得


=== wc コマンド
#標準出力やファイルのサイズ、単語数、行数などの情報を取得する# +

* `-l`:ファイルの行数表示
* `-c`:文字数表示
* `-w`:単語数表示


=== ★find コマンド
#指定した条件に該当するファイル、ディレクトリを見つける# +

* `-name`:指定した文字列で検索
* `-atime 〇〇`:〇〇日までアクセス利用していたものを検索
* `-mtime`:ファイルやディレクトリの最終更新日時を利用して検索
* `-user`:ファイルの所有者で検索
* `-type`:ファイルのタイプで検索（ファイルか、ディレクトリか、シンボリックリンクか）


=== split コマンド
#ファイルを特定のサイズで分割する# +

* `-b`:バイト数指定でファイルを分割
* `-l`:行数指定でファイルを分割
