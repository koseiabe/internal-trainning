= Ansible

== セクション４：ハンズオン実践

=== ハンズオン５：コピー（ファイルの中身を指定して）
* `content:`:playbookに記述することでテキストデータの中身を指定することができる

|===
   # 5.ファイルの中身を指定してコピー +
    - name: Ansible copy file to remote server +
      copy: +
        content: | +
          <!DOCTYPE html> +
          <html> +
          <head> +
          <meta charset="UTF-8"> +
          </head> +
          <body> +
          <h1>このページはcopyモジュールのcontentパラメータを使用してコピーしたページです！</h1> +
          </body> +
          </html> +
        dest: "/var/www/html/index.html" +
|===
* htmlファイルの格納場所は +
Redhat系→/usr/share/nginx/html/ +
Ubuntu系→/var/www/html/ +


=== ハンズオン６：vars変数（playbook内定義）
* `vars:`:変数定義を表す +
※ playbook内で変数定義する際は、サマリ部に記述する
* `{{ 変数 }}`:変数の展開 +
※ 同じパスが何度も出てくる場合などに定義 +
※ playbookの規模が小さいときなど

|===
|変数定義例
|vars: +
  html_path: /var/www/html/ +
|変数展開例
|dest: "{{ html_path }}/index.html"
|===

=== ハンズオン７：vars変数（外部ファイル定義）
* 外部ファイルの読み込みは外部ファイルを用いるタスクの直前に記述すること
* `include_vars`:このモジュールは、外部ファイルに記述した変数の設定を一括で読み込むことできる
* `html_path: /var/www/html/`:外部ファイルでの変数定義例 +
※ yaml形式のファイルにて

|===
　　#5. 外部ファイルの読み込み
     - name: Read external variable file +
       include_vars: vars.yaml +
 +
    # 6. コピー +
    - name: Ansible copy file to remote server +
      copy: +
        content: | +
          <!DOCTYPE html> +
          <html> +
          <head> +
          <meta charset="UTF-8"> +
          </head> +
          <body> +
          <h1>このページはcopyモジュールのcontentパラメータを使用してコピーしたページです！</h1> +
          </body> +
          </html> +
        dest: "{{ html_path }}/index.html" +
|===

=== ハンズオン８：register変数
* `register: <変数>`:指定したタスクの実行結果を変数に格納することができる変数 
* `when: <変数>.changed`:タスクステータスがchangedの時にタスクを実行をするモジュール
